# Real Estate Website

A modern and responsive Real Estate web application developed to help users explore, view, and manage property listings easily. The project provides an interactive user interface with smooth navigation and a clean design for a better user experience.

## Features

- Responsive and modern UI design
- Property listing section
- Property details page
- Smooth animations and transitions
- User-friendly navigation

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript (ES6+)
- GSAP
- Framer Motion

### Backend
- Node.js
- Express.js

### Database
- MySQL

### Tools
- VS Code
- Git & GitHub

## Project Objective

The main objective of this project is to create a user-friendly real estate platform where users can browse properties with an attractive and responsive interface.
